Features and plans

A clear separation between implemented systems, prototypes, and future plans.

Reading feature status

A design description is not a release guarantee. This page separates reported development progress from the public roadmap. The website repository contains the website, so game implementation cannot be verified from it.

Implemented navigation

Confirmed by the developer on November 13, 2026: a Lambert solver and hierarchical patched-conic escape and capture are implemented. The planner can plot a route to a moon orbiting a planet around a binary companion star. See Astronavigation for how these transfers work. This status is developer-reported; no game-source revision or build was audited for this wiki.

Reported development progress

The following milestones have been described during development. They have not been independently checked against a current game build for this wiki.

  • Unity planetarium with floating-origin and scale handling.
  • Double-precision orbital data and deterministic two-body propagation.
  • Geographical polygons for district-scale management.
  • Atmosphere-history and geological-resource generation work.

Systems being developed

  • Ship schedules, event-based time warp, shuttle information, and transport planning.
  • Colony industry, resource processing, and supply-chain balance.
  • Planetary environment generation and its connection to mineral resources.

These entries indicate active work, not a claim that each system is finished or available in a public release.
